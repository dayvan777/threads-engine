Демо-режим: сторінку відкрито поза claude.ai, тому замість справжнього перекладу — транслітерація, щоб перевірити верстку.
  • Читаю документ
  • Перекладаю
  • Верстаю переклад

Файл не залишає браузер — назовні йде лише текст сегментів. Переклад виконує Claude з вашого облікового запису; перший запуск попросить дозвіл.

Обмеження: скани без текстового шару не перекладаються (потрібен OCR); текст поверх складних фонів закривається плашкою кольору тла; повернуті сторінки лишаються як є. Для бездоганного результату є консольна версія — pdf-translator у репозиторії.
