# PDF Translator: немецкий → украинский с сохранением вёрстки

Переводит PDF-документы (по умолчанию de → uk), **сохраняя макет**: позиции
блоков, размеры и начертания шрифтов (жирный/курсив), цвета текста,
выравнивание (по левому/правому краю, по центру, по ширине), межстрочный
интервал, колонки, таблицы, картинки, векторную графику, ссылки и закладки.

| Исходник (DE) | Результат (UK) |
|---|---|
| текст удаляется точечно | перевод вставляется в те же рамки тем же кеглем |

## Как это работает

1. **Извлечение** (PyMuPDF): со страницы снимаются все текстовые сегменты с
   их координатами, доминирующим кеглем, цветом, жирностью/курсивом,
   семейством (serif/sans/mono), выравниванием и интерлиньяжем. Переносы
   слов на концах строк склеиваются, ячейки таблиц и колонки распознаются
   по горизонтальным разрывам.
2. **Перевод**: уникальные сегменты переводятся одной пачкой выбранным
   движком (с кэшем — повторяющиеся колонтитулы переводятся один раз).
3. **Перевёрстка**: оригинальный текст удаляется редактированием
   (картинки и графика не затрагиваются), перевод вставляется в исходную
   рамку с тем же стилем. Если перевод длиннее оригинала, рамка сначала
   расширяется в сторону свободного места (например, заголовок растёт
   вправо), и только когда расти некуда — текст пропорционально ужимается,
   чтобы гарантированно не вылезти из макета. Числа, даты и прочие
   сегменты без букв не трогаются вовсе.

Про шрифты честно: немецкие шрифты, встроенные в PDF, почти никогда не
содержат украинских букв (і, ї, є, ґ), поэтому переведённый текст набирается
метрически близкими шрифтами с полной кириллицей — Noto / DejaVu /
Liberation (ищутся в системе автоматически, с сохранением serif/sans/mono
и жирных/курсивных начертаний). Кегль, цвет и позиция остаются исходными.

## Установка

```bash
cd pdf-translator
pip install -r requirements.txt      # pymupdf, deep-translator, fonttools
# или как пакет с командой pdf-translate:
pip install .
```

Нужны шрифты с кириллицей (на Linux обычно уже есть):
`sudo apt install fonts-dejavu` или `fonts-noto-core`.

## Использование

```bash
# бесплатно, без ключей (Google Translate через веб):
python -m pdf_translator vertrag.pdf
# → vertrag.uk.pdf

# явные параметры:
python -m pdf_translator vertrag.pdf -o vertrag_uk.pdf \
    --provider google --source de --target uk

# лучшее качество перевода:
DEEPL_API_KEY=... python -m pdf_translator vertrag.pdf --provider deepl
ANTHROPIC_API_KEY=... python -m pdf_translator vertrag.pdf --provider claude

# только часть страниц + кэш перевода между запусками:
python -m pdf_translator vertrag.pdf --pages 1-3,7 --cache vertrag-cache.json
```

Полный список опций: `python -m pdf_translator --help`.

### Движки перевода

| `--provider` | Качество de→uk | Что нужно |
|---|---|---|
| `google` (по умолчанию) | хорошее | интернет, ключ не нужен |
| `deepl` | отличное | `DEEPL_API_KEY` (есть бесплатный тариф), `pip install deepl` |
| `claude` | отличное, лучше всех держит терминологию | `ANTHROPIC_API_KEY`, `pip install anthropic` (модель по умолчанию `claude-opus-5`, можно сменить через `--model`) |
| `libre` | среднее | свой/публичный сервер LibreTranslate (`--libre-url`) |
| `mock` | псевдоперевод | ничего (офлайн-проверка вёрстки) |

Пара языков не зашита намертво: `--source`/`--target` принимают любые коды,
которые поддерживает выбранный движок (например `--source de --target ru`).

## Проверка результата

В конце печатается отчёт: сколько сегментов переведено и какие пришлось
ужать (и до какого размера), чтобы вписать в рамку — эти места стоит
глянуть глазами. Быстро сравнить постранично:

```bash
python examples/make_sample.py sample_de.pdf      # тестовый немецкий PDF
python -m pdf_translator sample_de.pdf --provider mock
```

## Тесты

```bash
pip install pytest
python -m pytest tests/
```

Тесты гоняют полный конвейер на сгенерированном немецком документе
(заголовки, колонки, таблица, картинки) с офлайн-движком `mock` и проверяют,
что кириллица встала в исходные рамки с тем же кеглем, цветом, жирностью и
выравниванием, а картинки/графика/числа не изменились.

## Ограничения

- **Сканы не переводятся**: если у страницы нет текстового слоя, она
  остаётся как есть (утилита предупредит). Сначала прогоните OCR
  (например, `ocrmypdf -l deu`).
- Текст, нарисованный внутри картинок, не переводится.
- Если внутри одного абзаца перемешаны стили (одно жирное слово в строке),
  абзац набирается доминирующим стилем.
- Аннотации-комментарии, попавшие в зону текста, удаляются вместе с ним
  (ссылки восстанавливаются).
